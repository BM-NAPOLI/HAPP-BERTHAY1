# 🎂 HAPP-BERTHAY1

A small interactive birthday surprise website built with **HTML, CSS, and JavaScript**.

The project was created as a personal digital birthday gift, combining animations, interactive scenes, a birthday cake, candles, confetti, music, and a letter.

## ✨ Features

* 🌙 Animated night/day-style background
* ⭐ Dynamic stars
* 🎁 Interactive gift box
* 🌸 Animated flower
* 🎂 Birthday cake with 14 candles
* ✨ Candle-by-candle animation
* 🎉 Confetti effect
* 🎵 Background birthday music
* 💌 Animated envelope
* ✍️ Letter typing effect
* ❤️ Final birthday scene
* 📱 Responsive design

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/BM-NAPOLI/HAPP-BERTHAY1.git
```

Open the project folder:

```bash
cd HAPP-BERTHAY1
```

Then open `index.html` in your browser.

## 🎮 How It Works

The website is divided into several interactive scenes:

1. **Opening** — The birthday date and introduction.
2. **Gift** — Click the gift to open it.
3. **Flower** — A flower animation appears.
4. **Birthday** — A cake with 14 candles and a wish button.
5. **Letter** — The envelope opens and the birthday letter is typed automatically.
6. **Final Scene** — The birthday message and signature appear.

## 🎵 Music

The project uses a local MP3 file:

```text
song/bb.mp3
```

The music is controlled through JavaScript and can be customized to play different parts of the song during the experience.
